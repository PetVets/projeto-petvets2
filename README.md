## Sobre o projeto
Este **Projeto PetVets** é uma aplicação fullstack desenvolvida como um teste de funcionalidade de funções no Git no curso de desenvolvimento de sistemas, oferecido pelo SENAI Sorocaba - Gaspar Ricardo Júnior, ministrado pelo Prof. [Vedilson Prado](https://github.com/vedilsonprado).O projeto **PetVets** consiste no desenvolvimento de um site para facilitar o cadastro de informações em clínicas veterinárias. Seu objetivo é organizar os dados de forma prática, tornando o gerenciamento mais rápido e eficiente. O sistema possui as funções de cadastro de pets, tutores, veterinários e espécies, permitindo que todas as informações fiquem armazenadas em um único lugar. Dessa forma, a clínica pode manter os registros organizados e facilitar o atendimento. Além de atender às necessidades de organização, o projeto também tem como objetivo colocar em prática os conhecimentos adquiridos durante o curso, como o desenvolvimento de API RESTful, o uso de Banco de Dados Relacional e a integração entre o backend e o frontend utilizando JavaScript. A aplicação permite o gerenciamento completo (CRUD) de plantas, incluindo validação de regras de negócio e persistência de dados.

## Tecnologias utilizadas

### Backend
- **Java 17** Principal linguagem.
    - **Spring Boot:** Framework para a criação de api

### Banco de Dados
- **MySQL:** Banco de Dados Relacional.

### Frontend
- **HTML5 & CSS3:** Estrutura semântica e estilização
- **JavaScript:** Lógica do cliente e consumo da APi.

## Como executar o projeto

### 1. Banco de Dados
- Crie o banco de dados MySQL executando o script SQL: 
```sql
CREATE DATABASE db_petvets;
```

### 2. Backend
- Clonar repositório.
- Configure o arquivo application.properties com as suas credenciais do MySQL.
- A API rodará em: `hhtp://localhost:8080`

### 3. Frontend
- Navegue até a pasta do Frontend.
- Acesse o index.html no navegador.
